# Drop Lab

Premium filtered-showerhead brand site for **Drop Lab**.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Theme

- Display: Fraunces
- UI: Sora
- Palette: ink teal, aqua mist, foam backgrounds
- Hero: full-bleed shower imagery with brand-first hierarchy
