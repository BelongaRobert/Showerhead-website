# EVERYDAY

Premium filtered shower systems — market-ready product experience for **EVERYDAY**.

Brand palette: Deep Sea `#0F2D3A`, Sand `#F2EFEA`, Fog Blue `#7FA1B2`. Typography: Outfit (UI) + Cormorant Garamond (editorial).
