# Dr. Droppy Shopify Theme

Working Online Store 2.0 theme for **Dr. Droppy** — science-backed filtered shower water.

Homepage follows a Cold Life–style product landing layout (gallery + buy box, reviews, benefits, problem, science, FAQ) with cream, navy, and sky-blue brand visuals.

## Connect / sync

Branch: **`cursor/shopify-theme-36e5`**

After pushing, Shopify should auto-sync if already connected. Then:

1. Online Store → Themes → Publish this theme
2. Edit theme → open the **Product buy box** section → choose your filtered shower head product
3. View store
